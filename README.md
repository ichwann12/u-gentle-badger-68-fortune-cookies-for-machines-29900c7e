# Fortune Cookies for Machines

One fortune cookie message an AI agent would get — a single line:

> You will meet a tall, dark stranger. He is a server rack, and he already knows your password.

`main.ts` (Node 22, stdlib only, no network, no wall clock) reads the entry
from `entry.txt` and writes it to the output directory given by
`MAKEFUN_BOT_DIR` / `MAKEFUN_OUTPUT_DIR`.
